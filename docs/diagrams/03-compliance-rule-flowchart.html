Statutory obligation rule flow — facts to a dated, gated task

One chain from the client record to the board: entity type and scope decide the services, VAT and payroll add theirs, the statute sets a date, and the calendar rolls it back to a working day before the partner gate.

01 · Input

Facts set the default set

The client record carries entity type, VAT category A–F, payroll, year end, incorporation date and turnover band. An explicit Client.services scope overrides the derived set.

02 · Branches

Two flags change the outcome

A VAT registration adds VAT201; a payroll flag adds EMP201 and EMP501. Neither flag set means no additional return — the derived or quoted scope stands alone.

03 · Date

Calendar date becomes working date

Companies Act and Tax Administration Act rules set the date first. Weekends and SA public holidays then roll it back to the previous business day before the partner gate.
