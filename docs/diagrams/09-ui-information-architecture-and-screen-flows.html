User Interface Information Architecture & Screen Flows

Complete hierarchical screen map translating the South African accounting practice requirements into an intuitive Twenty-style CRM layout: persistent shell navigation, master practice registers, 4-tab client record views, and external document/invoicing outputs.

1. The Record Show Architecture

In standard CRM UX, an existing client record is never kicked to an isolated page for estimation. Clicking a client row (MUS-875) in the master directory opens the 4-Tab Record Show View, placing Statutory Profile, Deadlines, 12-Month Fee Matrix, and SharePoint Vault under a unified breadcrumb.

2. Standalone vs Nested Quotes

The sidebar link "New Quote Calculator" is dedicated to quoting prospective clients before they exist in the register. For existing clients, the estimate lives directly on Tab 3 of their profile, with instant streaming A4 PDF and formula-driven Excel exports.

3. Clean Separation of Concerns

By defining this screen blueprint before writing code, every UI button, route, and state transition maps directly to the South African statutory requirements (Companies Act s30, Tax Administration Act s25) without guessing layout geometry.
