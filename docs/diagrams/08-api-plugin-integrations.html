Twenty CRM External API Plugins & Connected Services

Architectural diagram illustrating Twenty CRM as the unified operational core, connecting to self-hosted Documenso (E-Signatures), Microsoft Graph API (SharePoint Client Vaults), Xero API (15% South African VAT Invoicing), and Paystack (Instant EFT Payments).

01 · Documenso E-Sign

Self-hosted open-source digital signing provides legally binding contracts under SA ECTA s13 without recurring SaaS subscription costs, automatically activating won leads via webhook.

02 · MS Graph Client Vault

Headless MSAL daemon provisions standard folder structures in SharePoint for signed contracts, tax receipts, and KYC files, completely isolating external clients from M365 tenant logins.

03 · Xero 15% VAT Sync

Synchronizes retainer fees and out-of-scope billable hours with South African standard 15% VAT (OUTPUT2 tax code) as DRAFT invoices, requiring partner sign-off before dispatch.

04 · Paystack Payment Rails

Integrates localized South African payment checkout links (Capitec Pay, Ozow Instant EFT, Visa, Mastercard) directly into client proposal notifications and billing notices.
